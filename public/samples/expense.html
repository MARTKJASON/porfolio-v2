What I manage

I own the path from development to production. UAT is the last check before release: real users confirm the system does what they need, and anything they find gets tracked, fixed and retested.

Development→ QA testing→ UAT→ Production

What I do as Project Manager

01

Plan and track

Manage user stories, tasks and priorities, and keep project progress visible.

02

Coordinate the team

Keep developers, QA and stakeholders aligned so requirements are understood and delivered.

03

Facilitate User Acceptance Testing and coordinate feedback, issue tracking and validation.

04

Take part in PR reviews, staging validation, testing and production-readiness checks.

05

Release

Help coordinate deployment and make sure the production release goes smoothly.

Balance project management with hands-on QA and development work.

AI-Driven Development (AIDD)

The team uses AI coding tools such as Claude and Codex for implementation, which speeds up delivery. People stay in charge of quality: every change still goes through code review, testing, debugging and validation before it ships.

Why it matters

This is my current role, and the latest step in my path from Software QA to Full-Stack Developer to Project Manager / Technical Lead. It covers the whole of delivery: planning the work, keeping the team in step, getting real users to confirm it works, and getting it released.
